# Homebrew tap for provio

[provio](https://github.com/writ-agent/provio): a safety floor your AI agents can't get under.

```bash
brew install writ-agent/provio/provio
provio scan     # what would provio have caught in your agents' last 30 days?
provio init
```

The formula installs the prebuilt, signed release binary (checksums from the
release's `checksums.txt`). It is generated by `scripts/gen_distribution.py`
in the main repository; do not edit it by hand.
